# Quick Start Guide

Get started with AI SuperToolbox in 5 minutes!

## Step 1: Get Your Claude API Key (2 min)

1. Visit [console.anthropic.com](https://console.anthropic.com/)
2. Sign up or log in
3. Navigate to API Keys section
4. Create a new API key
5. Copy the key (starts with `sk-ant-`)

**Note**: Claude offers $5 in free credits for new users to test the API.

## Step 2: Install Scriptable (1 min)

1. Open App Store on your iPhone
2. Search for "Scriptable"
3. Download and install (it's free!)
4. Open Scriptable

## Step 3: Install AI SuperToolbox (1 min)

1. In Scriptable, tap the **+** button (top right)
2. Copy the contents of `AI_SuperToolbox.js` from this repo
3. Paste into the new script
4. Tap the script name at top
5. Name it: **AI SuperToolbox**
6. Tap **Done**

## Step 4: Configure API Key (30 sec)

1. Tap to run the **AI SuperToolbox** script
2. Select **⚙️ Settings & Setup**
3. Select **🔑 Set API Key**
4. Paste your Claude API key
5. Tap **OK**

## Step 5: Test It! (30 sec)

1. Return to main menu
2. Select **⚡ Quick Tools**
3. Select **🎯 Summarize Text**
4. Enter any text to test
5. See the AI-powered summary!

## Common First-Time Issues

### "API key not configured"
→ Make sure you completed Step 4 above

### "Network error"
→ Check your internet connection

### Can't find script in Shortcuts
→ Make sure you named it exactly **AI SuperToolbox** in Scriptable

### Tools are slow
→ First request may be slower; subsequent ones are faster
