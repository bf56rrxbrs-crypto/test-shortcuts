# Shortcuts Gallery

Visual examples of the prebuilt shortcuts in action.

## 🎯 Quick Summarize

**What it does**: Instantly summarize any text

**Example Flow**:
```
1. You're reading a long article in Safari
2. Select a few paragraphs of text
3. Tap "Share" button
4. Choose "Quick Summarize"
5. Get instant summary in notification
```

**Input Example**:
```
Artificial intelligence (AI) is transforming the technology landscape 
at an unprecedented pace. From healthcare to finance, AI applications 
are revolutionizing how we work and live. Machine learning models can 
now predict diseases, optimize supply chains, and even create art. 
However, this rapid advancement also raises important questions about 
ethics, privacy, and the future of work...
```

**Output Example**:
```
AI is rapidly transforming multiple industries including healthcare and 
finance through machine learning applications. While offering benefits 
like disease prediction and supply chain optimization, it also raises 
concerns about ethics, privacy, and employment impact.
```

## ✅ Grammar Check

**What it does**: Fix grammar and spelling errors

**Example Flow**:
```

deadline. Can we setup a meeting to discuss it's details?

**Output Example**:
```

project you're working on. There seems to be some confusion about the 
deadline. Can we set up a meeting to discuss its details?

## 🔧 Code Explainer

**What it does**: Explain code in plain English

**Example Flow**:
```
1. Find confusing code snippet online
2. Copy it
3. Share → "Code Explainer"
4. Read clear explanation
```

**Input Example**:
```javascript
const result = arr.reduce((acc, val) => 
  acc + (val % 2 === 0 ? val : 0), 0);
```

**Output Example**:
```
This code sums up all even numbers in an array.

Here's how it works:
1. reduce() iterates through the array
2. For each value, it checks if it's even (val % 2 === 0)
3. If even, adds it to the accumulator
4. If odd, adds 0 (ignores it)
5. Returns the final sum starting from 0

Example: [1,2,3,4,5] → 2+4 = 6
```

## Tips for Best Results

✅ **Be Specific**: More context = better results  
✅ **Try Options**: Some tools offer multiple responses  
✅ **Iterate**: Run same text through different tools  
✅ **Combine Tools**: Chain shortcuts for complex tasks  
✅ **Save Favorites**: Keep best shortcuts on home screen

- **First Use**: May take 2-3 seconds
- **Subsequent Uses**: Usually under 1 second
